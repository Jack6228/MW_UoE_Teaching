# Core Logging Exercises with stratapy

This ``Demo_Notebook.ipynb`` notebook is designed to help you learn how to use the ``stratapy`` package for visualising and analysing core log data. It includes exercises that will guide you through loading, plotting, and saving core log data.

## 🚀 Run Interactively on MyBinder

These exercises are designed to be run online without the need to install Python or any software on your device.

Click the badge below or visit [https://mybinder.org/v2/gh/Jack6228/MW_UoE_Teaching/main?filepath=Demo_Notebook.ipynb](https://mybinder.org/v2/gh/Jack6228/MW_UoE_Teaching/main?filepath=Demo_Notebook.ipynb) to launch the notebook in your browser.

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Jack6228/MW_UoE_Teaching/main?filepath=Demo_Notebook.ipynb>)

## 📋 Contents

- `Demo_Notebook.ipynb`: The main notebook containing exercises and instructions for using the ``stratapy`` package.
- Two tutorial ``.csv`` files based on the 49-22-55 core log
- An ``answers`` folder containing the solutions to the exercises, both as ``.csv`` files and as ``png`` images.
- The ``answers/reference`` folder contains some styled versions of the same logs, to illustrate how you can customise the appearance of your plots.
